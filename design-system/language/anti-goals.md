# Anti-Goals

What this system is NOT and explicitly rejects:
1. **No Material/Tailwind Defaults**: Avoid using generic drop-shadows, default roundness, or blue highlight focus rings.
2. **No Nature Stickers**: Do not place arbitrary illustrations of leaves, trees, or animals. Nature is rhythm and growth algorithm only.
3. **No Smooth Transitions**: Avoid generic linear or cubic ease-in transitions on element states. Every state shift on an element already on the page is immediate. A surface that was not rendered a frame ago may arrive — but on the stepped clock, by growing its paper boundary around fixed content, never on an eased curve (see `language/motion.md`).
4. **No Green Tick Status Language**: Do not represent success as a checkbox or green check icon. Status is organic change.
5. **No Dark Mode or Lightness Inversion**: Do not build dark skins, inverted themes, or dark-mode runtime branches for this system. Every skin is a light paper — a dark ground collapses the grain/multiply/ink material language, so lightness polarity is not a theming axis. An application with its own `.dark` theme keeps the system's chrome on its light paper or omits the system there (see `language/theming.md`).
