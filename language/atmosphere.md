# Atmosphere

Atmosphere defines the ambient environment of the system:
1. **Stepped breathing grid**: A subtle, slow-pulsing background grid of hairlines desynchronized using LCG values.
2. **Warm background bloom**: Dynamic radial gradients layer soft colors (cream, amber, red) behind the sheet.
3. **Deterministic Ambience**: Everything is mathematically seeded to avoid clock drift and keep build results byte-identical.

## Mounting: once per chrome root

The ambient stack (breathing grid + background bloom) mounts **once per chrome
root** (`mountCardinality: "once-per-root"` in `recipes/atmosphere.recipes.json`)
— never per tile, card, or list item. The zoo mounts it exactly once, directly
under its root; sections and tiles carry no ambient layers of their own.

The default stack is the non-weather atmosphere only. **Weather is opt-in and
disabled by default** (`weatherEnabledByDefault: false`); a consumer adds a
weather field explicitly where it wants one.

## Cost contract

The generator defaults are the cost contract, enforced by the validation gate
(`scripts/lib/atmosphere-contract.mjs`), not by prose:

- **6–51 particles per weather field** (`wind`, `rain`, `fleck`, `drift`,
  `firefly`, `flake`, `haze`, `sunpool`).
- **Exactly three blooms**, generated by `bloomData()` in
  `design-system/source/zoo/effects/atmosphere.mjs` — the same module that
  declares the envelope as `atmosphereContract()`.

## Fixed-behind-scope pattern

1. **Chrome root**: the element hosting the ambient stack carries
   `.ontwerp-root`, which declares `isolation: isolate` — the stack's stacking
   context, so fixed ambience cannot paint over UI outside the subtree.
2. **Ambient descendants**: `.grid` and `.bloom` mount inside the scope tree so
   they inherit its tokens. In scoped builds they are emitted under the scope
   class (`.ontwerp .grid`), so the chrome root sits one element below the
   token scope.
3. **Content above**: the ambient layers paint at `z-index: 0`; content is
   lifted above them at `z-0` or higher (the zoo's `.sheet` sits at `z-index: 1`).

Ambient layers mounted outside the scope tree, or a chrome root without
`isolation: isolate`, fail the fixed-behind-scope contract.
