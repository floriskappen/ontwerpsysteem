## 3. Drafted v1.0.0 entry (for approval)

The complete per-ID entries live in `CHANGELOG.md` → `## Unreleased`; on approval,
`npm run release --write` versions them as:

> **1.0.0 — MAJOR/BREAKING**, because the unreleased set contains breaking contract changes.

Breaking items requiring migration notes (all already written into the Unreleased propagation
block):

1. **Keyframe names** — every shipped `@keyframes` now carries the `ontwerp-` prefix; consumer CSS/JS
   naming shipped keyframes must adopt the prefixed names.
2. **Tailwind theme namespace** — every theme variable carries the `ontwerp` segment
   (`--color-ontwerp-paper`); consumers rename `@theme`-derived utilities accordingly.
3. **Live aliases** — CSS outputs keep alias chains as `var()` references instead of flattening to
   literals; consumers that parsed literals must read resolved values from the JS output or manifest.
4. **Weight token vs face** — Archivo ships a variable face genuinely covering 400–700; faux-weight
   workarounds should be deleted.
5. **Utility mark reserved for data** — mono-uppercase is for numerals/counts/identifiers/coded
   events only; prose labels/subtitles/eyebrows return to Archivo lowercase (de-ontwerper already
   made this correction by hand).

Additive highlights: scoped token/component/effects CSS, `.ontwerp-boundary`, the `data-skin` slot,
complete skins, fonts.css + font gates, effects data module, status mark + segmented control,
light-only theming statement, the values-only shadcn adapter, and the three-case integration guide.
