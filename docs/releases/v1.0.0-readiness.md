## 3. Drafted v1.0.0 entry (for approval)

The complete per-ID entries live in `CHANGELOG.md` → `## Unreleased`; on approval,
`npm run release --write` versions them as:

> **1.0.0 — MAJOR/BREAKING**, because the unreleased set contains breaking contract changes.

Breaking items requiring migration notes (all already written into the Unreleased propagation
block):

1. **Keyframe names** — every shipped `@keyframes` now carries the `ontwerp-` prefix; consumer CSS/JS
   naming shipped keyframes must adopt the prefixed names.
2. **Tailwind theme namespace** — every theme variable carries the `ontwerp` segment
   (`--color-ontwerp-paper`); consumers rename `@theme`-derived utilities accordingly.
3. **Live aliases** — CSS outputs keep alias chains as `var()` references instead of flattening to
   literals; consumers that parsed literals must read resolved values from the JS output or manifest.
4. **Weight token vs face** — Archivo ships a variable face genuinely covering 400–700; faux-weight
   workarounds should be deleted.
5. **Utility mark reserved for data** — mono-uppercase is for numerals/counts/identifiers/coded
   events only; prose labels/subtitles/eyebrows return to Archivo lowercase (de-ontwerper already
   made this correction by hand).

Additive highlights: scoped token/component/effects CSS, `.ontwerp-boundary`, the `data-skin` slot,
complete skins, fonts.css + font gates, effects data module, status mark + segmented control,
light-only theming statement, the values-only shadcn adapter, and the three-case integration guide.

## 4b. Visual pass performed against the rendered zoo

A headless-browser pass over the built zoo (all twelve skins, keyboard focus, `prefers-reduced-motion:
reduce`, and 375/768/1440px viewports) was run and is the source of the two corrections above it. What it
observed, at the commit in the header:

- **Reduced motion:** no element retains a running animation under `reduce`; rest poses render as finished.
- **Skins:** all twelve reskin coherently, and the destructive pigment stays visually distinct from the
  accent in each, including the skins where the two are nearest.
- **Focus (corrected):** buttons had a focus indicator in the showcase's page reset only, which is not part
  of the bundle — consumers importing the component CSS received `.btn` with no indicator. Now shipped.
- **Responsive (corrected):** the three fluid type ranges existed in prose only, so the document measured
  773px wide in a 375px window. Now 423px; type scales 72px→158.4px across the range.

Two findings were recorded rather than acted on, because both are visual decisions rather than defects
(`V1_WORKER_NOTES.md`): at its 72px floor the masthead still overruns a 375px viewport by ~48px, and
`--color-text-quiet` — the field-label colour — measures 3.0–3.3:1 across all twelve skins, below WCAG AA
for normal text. Neither is a regression; the second is faithful to the base skin, which measures 3.27:1.

Screenshots are session artifacts and are not committed. They do not substitute for §5 — a machine can
confirm a rule exists and a measurement holds; it cannot approve how the system looks.
