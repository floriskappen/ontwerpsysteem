# Roadmap feedback — utility-mark-canonical-examples

The remediation entry itself was accurate, but the roadmap let the contradiction it
targets survive for a full release cycle: Change 13 published the tightened utility-mark
rule as documentation without gating the canonical zoo examples against the new rule, so
"what correct looks like" kept teaching the old treatment until the release audit caught
it. Future roadmap entries that publish a normative language rule should carry a same-pass
conformance gate over the worked examples (source or generated), not trust a later audit
to notice the divergence.
