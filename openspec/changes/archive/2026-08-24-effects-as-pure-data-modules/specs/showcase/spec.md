## ADDED Requirements

### Requirement: Showcase renders effects through the data-derived wrappers

The showcase SHALL produce its effect markup (the ambient grid, seed heads, dividers, and weather fields) through the markup wrappers that are built on the effect data functions, so the zoo is the first consumer of the same data contract the bundle ships. Regenerating the showcase from unchanged inputs SHALL keep its effect markup byte-identical to the accepted baseline.

#### Scenario: Effect markup comes from the data-derived wrappers

- **WHEN** the showcase is generated
- **THEN** its effect markup is produced by wrappers that call the effect data functions
- **AND** no effect markup is generated by a path independent of those data functions

#### Scenario: Effect output stays stable across rebuilds

- **WHEN** the showcase is regenerated from unchanged inputs
- **THEN** its effect markup is byte-identical to the accepted baseline
